# AutoLid - поиск лидов в чатах Telegram и VK с автоответом

Программа следит за чатами Telegram и группами/беседами VK, находит сообщения, где люди ищут
исполнителя учебной работы (контрольные, курсовые, задачи по экономике и т.п.), присылает их
в ваш Telegram-бот с готовым ответом и по желанию сразу отвечает лиду сама - **реплаем на его
сообщение прямо в чате** (в VK - комментарием или ответом в беседе), чтобы быть первым откликнувшимся.

```
чаты TG / группы VK ──► фильтр по ключевым словам ──► ИИ проверяет и пишет ответ ──► ваш бот
     (из папок)          (мгновенно, без затрат)       (пачками, быстро)             ├─ кнопка «Отправить»
                                                                                      └─ или автоответ
```

## Быстрый старт (Windows)

1. Установите Python 3.10 или новее с https://www.python.org/downloads/
   (при установке поставьте галочку **Add python.exe to PATH**).
2. Запустите **`setup.bat`** - мастер настройки спросит по очереди:
   - **api_id и api_hash Telegram** - см. ниже, 1 минута;
   - **номер телефона и код** - вход в Telegram-аккаунт, с которого читаются чаты и пишутся ответы;
   - **токен бота** - куда будут приходить лиды; после этого откройте бота и нажмите /start;
   - **токен VK** - можно пропустить, если VK не нужен.
3. Положите файлы со ссылками в папки `chats/telegram` и `chats/vk` (см. ниже).
4. Запустите **`start.bat`**. Окно не закрывайте - пока оно открыто, программа работает.

На Linux/macOS всё то же самое через `./setup.sh` и `./start.sh`.

Ключ и модель ИИ задаются через `change_ai.bat` / `./change_ai.sh` (подробнее ниже). Проверить фильтр и ИИ на примерах сообщений: `test.bat`.

## Что понадобится

### api_id и api_hash Telegram
1. Откройте https://my.telegram.org, войдите по номеру телефона.
2. **API development tools** → заполните App title и Short name любыми словами (например `AutoLid` / `autolid`),
   Platform - Desktop → **Create application**.
3. Скопируйте **App api_id** и **App api_hash** в мастер настройки.

### Бот для уведомлений
В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя → скопируйте токен.
Лиды получает и управляет ботом **только аккаунт из `config.yaml` → `bot.admin_usernames`**.
С этого аккаунта один раз откройте бота и нажмите `/start` - без этого Telegram не даёт боту
писать человеку. Всем остальным бот отвечает «Нет доступа». Если список пуст, админом станет
первый, кто нажмёт `/start`. Несколько человек: `admin_usernames: ["first_nick", "second_nick"]`.

### Токен VK
Нужен токен пользователя с правами на стену, группы и сообщения:

1. Войдите во VK в браузере.
2. Откройте ссылку:
   `https://oauth.vk.com/authorize?client_id=2685278&scope=messages,wall,groups,offline&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&revoke=1`
3. Нажмите «Разрешить». Откроется пустая страница - скопируйте **всю ссылку из адресной строки**
   и вставьте в мастер настройки (он сам вытащит `access_token`).

Если ссылка не сработала, токен можно получить через сервис vkhost.github.io (вариант Kate Mobile).
**Токен - это полный доступ к аккаунту, никому его не передавайте.**

## Как добавлять чаты

Две папки:

| Папка | Что класть |
|---|---|
| `chats/telegram` | `.txt` файлы со ссылками на чаты и каналы Telegram |
| `chats/vk` | `.txt` файлы со ссылками на группы, обсуждения и беседы VK |

Формат - **одна ссылка на строку**. Файлов может быть сколько угодно, программа сама проверяет
папки каждые 20 секунд и подхватывает новые ссылки без перезапуска. Удалили ссылку из файлов -
программа перестанет следить за этим чатом. Примеры форматов - в файлах `_ПРИМЕР.txt` в каждой папке.

```
https://t.me/studhelp_chat
@economics_students
https://t.me/+AbCdEf123456
```
```
https://vk.com/studhelp
https://vk.com/club123456
https://vk.com/topic-123456_789
https://vk.me/join/AbCdEf...
```

- **Telegram:** программа сама вступает в чаты - по одному раз в 45–90 секунд. Это специально:
  массовое вступление - самый частый повод для бана. 200 чатов подключатся примерно за 4 часа.
  Если Telegram попросит подождать - программа подождёт и продолжит сама.
  Лимит Telegram - 500 групп на аккаунт (1000 с Premium).
- **VK, группы:** открытые группы читаются без вступления (посты, комментарии, обсуждения), 25 групп
  за один запрос - база в тысячи групп опрашивается примерно за минуту. Если комментировать в группе
  могут только участники - программа вступит в неё сама в момент ответа.
  В закрытые группы программа подаёт заявку (с паузой 20–40 с между заявками, чтобы VK не выдал капчу)
  и начинает читать после одобрения - проверка раз в 30 минут. Частные группы - только по приглашению.
- **VK, беседы:** по ссылке-приглашению `vk.me/join/...` программа сама вступает в беседу и читает её
  в реальном времени. Беседы сообществ (вкладка «Чаты» в группе) - тоже через их ссылку-приглашение;
  ссылка на саму группу добавляет только её стену.
- Статус подключения и ошибки - команда `/chats` в боте. `/retry` - попробовать ещё раз чаты с ошибками.

## Как ищутся лиды

1. **Ключевые слова** (`keywords.yaml`) - каждое сообщение мгновенно получает баллы: просьба
   («помогите», «кто может», «кто шарит»), тип работы, дисциплина, вуз, срочность, оплата.
   Предложения конкурентов («сделаю», «выполню», «гарантия») дают минус. Окончания слов учитываются:
   «контрольная» найдёт и «контрольной», и «контрольную».
2. **ИИ** проверяет кандидатов пачками: лид это или нет, тип работы, предмет, вуз, срок, бюджет -
   и сразу пишет короткий ответ, который зовёт человека в личку.
   - сообщения с высоким баллом уходят ИИ сразу (отклик за секунды);
   - **глубокая проверка:** сообщения с малым числом ключевых слов тоже проверяются ИИ, но крупными
     пачками в фоне - чтобы не пропустить лидов, которые пишут нестандартно. Ограничена
     `ai.deep_scan_max_per_hour`, чтобы не тратить лишние токены;
   - если ИИ недоступен, сообщения с очень высоким баллом (`sure_score`) всё равно приходят в бот
     с шаблонным ответом, остальные проверяются, когда ИИ оживёт.
3. **Обучение на ваших кнопках:** «🚫 Не лид» и ручные отправки попадают в подсказку для ИИ как примеры.

Один и тот же текст, разосланный по многим чатам, приходит один раз. Сообщения старше 30 минут
(например, после выключения компьютера) игнорируются - отвечать на них уже поздно.

### Что можно настраивать без перезапуска
- `keywords.yaml` - ключевые слова, веса, пороги, стоп-слова (синтаксис описан в начале файла);
- `prompts/classify.txt` - кого считать лидом (профиль, исключения);
- `prompts/reply.txt` - стиль ответа (по умолчанию: коротко откликнуться в чате и позвать в лс);
- `prompts/templates.txt` - запасные шаблоны ответа на случай, если ИИ недоступен.

Проверить, как программа оценит сообщение: в боте `/test текст сообщения` или `test.bat`.

### Смена ИИ (провайдер, ключ, модель)
Запустите **`change_ai.bat`**: он покажет текущие настройки, спросит новый адрес API и ключ
(Enter - оставить прежние), загрузит список доступных моделей - выберите номер, - проверит,
что модель отвечает, и сохранит. Потом перезапустите `start.bat`. Подходят и модели Claude,
и OpenAI-совместимые (DeepSeek, GPT, Gemini и т.п.) - формат запросов программа выберет сама.

## Бот: режимы и кнопки

**Режимы** (`/mode`):
- **✋ Ручной** - приходит карточка лида с готовым ответом, вы жмёте «Отправить».
- **🤖 Автоответ** - программа сама отвечает лиду через 15 секунд: сначала пауза, потом аккаунт
  «печатает...», потом уходит ответ - как будто человек увидел сообщение и набрал текст. Пока идёт
  задержка, ответ можно отменить кнопкой. Действуют лимиты: не больше 15 ответов в час и 80 в сутки,
  одному человеку - не чаще раза в 72 часа. Всё меняется в `config.yaml` → `reply`
  (`delay_min`/`delay_max` - задержка, можно задать диапазон для случайности).

**Карточка лида:** ник автора (со ссылкой на профиль), чат, исходное сообщение, что понял ИИ
(тип работы, предмет, вуз, срок, бюджет) и готовый ответ ИИ. После каждой отправки бот присылает
отдельное уведомление «✅ Ответил @ник ...» с сообщением человека и тем, что ему ответили.

**Кнопки под лидом:** ✅ Отправить · 🔄 Другой текст · ✏️ Свой текст · 🚫 Не лид · ⛔ Игнор автора ·
🔗 Сообщение · 👤 Автор.

**Куда пишется ответ:** реплаем на сообщение лида прямо в том же чате, с вашего Telegram-аккаунта
(перед отправкой аккаунт несколько секунд «печатает»). В VK - там же, где написал лид: комментарием
под постом, ответом на комментарий, в обсуждении или в беседе - с упоминанием автора.

Другие варианты - в `config.yaml`:

| `reply.telegram_method` | `reply.vk_method` | Что делает |
|---|---|---|
| `chat` *(по умолчанию)* | `reply` *(по умолчанию)* | только ответом в чате |
| `chat_then_dm` | `reply_then_dm` | в чате, а если там писать нельзя (нет прав, комментарии закрыты) - в личку |
| `dm` | `dm` | только в личку |
| `dm_then_chat` | `dm_then_reply` | в личку, а если закрыта - в чате |

Если переключаетесь на личку, поправьте `prompts/reply.txt` - сейчас ответ зовёт человека «написать в лс».

**Команды:** `/status`, `/mode`, `/chats`, `/stats`, `/test`, `/pause`, `/resume`, `/retry`, `/help`.

## Безопасность аккаунтов

- Используйте **отдельный Telegram-аккаунт**, не основной, желательно не новый (с историей).
- Ответы в чате видят все - админы и антиспам-боты банят за рекламу. Поэтому ответ короткий и «человеческий»,
  без ссылок и слов «услуги/заказ». В чатах, где реклама исполнителей прямо запрещена, лучше не отвечать -
  удалите такие ссылки из базы.
- Если в чат писать нельзя (медленный режим, нет прав, аккаунт забанен) - ответ не отправится,
  а в карточке лида будет причина. Если аккаунт не может писать почти нигде - проверьте спам-блок через @SpamBot.
- При переключении на личку: Telegram ограничивает сообщения незнакомым людям. Если он посчитает отправку
  спамом (PeerFlood), программа сама поставит автоответы на паузу на 6 часов и сообщит в бот.
- Не ставьте `join_delay_min` меньше 30 секунд и не поднимайте лимиты отправки резко.
- В VK при капче или флуд-контроле автоответы тоже ставятся на паузу.

## Работа 24/7

Программа ловит сообщения, только пока запущена. Для круглосуточной работы держите компьютер
включённым или запустите на VPS с Linux: `./setup.sh`, затем `./start.sh` внутри `screen`/`tmux`
(или как службу systemd). Переносить можно всю папку целиком - вход в Telegram сохраняется
в `data/telegram.session`.

## Файлы

| Путь | Что это |
|---|---|
| `config.yaml` | все настройки (ключи, токены, лимиты) |
| `keywords.yaml` | ключевые слова и пороги |
| `prompts/` | тексты для ИИ и шаблоны ответов |
| `chats/telegram`, `chats/vk` | ваши базы ссылок |
| `data/` | база программы, сессия Telegram, логи (`data/logs/autolid.log`) |
| `autolid/` | код программы |
| `list_models.py` | вывести список моделей у текущего провайдера ИИ |

`data/telegram.session` и `config.yaml` содержат доступы к аккаунтам - не отправляйте их никому.

## Если что-то не так

- **Лиды не приходят в бот** - отправьте боту `/start`; проверьте `/status`; посмотрите `data/logs/autolid.log`.
- **«ИИ недоступен»** - провайдер ИИ не отвечает; программа продолжит работу по ключевым словам и сама
  вернётся к ИИ. Проверить: `test.bat`. Сменить модель или провайдера: `change_ai.bat`.
- **Чат в ошибках «чат не найден» / «ссылка недействительна»** - ссылка битая или приглашение истекло.
- **VK: «нет доступа к сообщениям»** - токен получен без права `messages`, беседы читаться не будут
  (стены групп работают). Получите токен заново по ссылке выше.
- **Сменить Telegram-аккаунт** - `setup.bat`, на вопрос «Оставить этот аккаунт?» ответьте «н».

## Разработка

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py check "кто может решить контрольную по макро? срочно"
```

Код лежит в `autolid/`:

| Модуль | |
|---|---|
| `app.py` | запуск и перезапуск всех фоновых задач |
| `tg.py`, `vk.py` | чтение чатов и отправка ответов |
| `keywords.py` | фильтр по ключевым словам |
| `ai.py` | запросы к ИИ (OpenAI-совместимые API и Claude) |
| `pipeline.py` | очередь сообщений: фильтр → ИИ → лид |
| `responder.py` | автоответы, задержки и лимиты |
| `bot.py` | Telegram-бот для уведомлений и управления |
| `db.py` | SQLite |
| `setup_wizard.py` | мастер настройки |
