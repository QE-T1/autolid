# Это пример — файлы, имя которых начинается с "_", программа не читает.
#
# Положите в эту папку любой .txt файл со ссылками на группы/беседы VK,
# по одной ссылке на строку. Новые ссылки подхватываются автоматически.
#
# Поддерживаемые форматы:
#   https://vk.com/groupname          — группа/паблик: новые посты и комментарии
#   https://vk.com/club12345          — то же по id (public12345, event12345 тоже можно)
#   https://vk.com/wall-12345_678     — ссылка на пост (возьмётся сама группа)
#   https://vk.com/topic-12345_678    — обсуждение в группе
#   https://vk.me/join/AbCdEf...      — ссылка-приглашение в беседу
#
# vk.ru и m.vk.com тоже понимаются. Строки, начинающиеся с #, — комментарии.
