# Это пример — файлы, имя которых начинается с "_", программа не читает.
#
# Положите в эту папку любой .txt файл со ссылками на чаты Telegram,
# по одной ссылке на строку. Можно класть сколько угодно файлов и дописывать их —
# программа сама подхватывает новые ссылки каждые 20 секунд.
# Удалили ссылку из файлов — программа перестанет следить за этим чатом.
#
# Поддерживаемые форматы:
#   https://t.me/username            — открытый чат или канал
#   t.me/username  или  @username    — то же самое
#   https://t.me/+AbCdEfGh123        — ссылка-приглашение в закрытый чат
#   https://t.me/joinchat/AbCdEf123  — старый формат приглашения
#   https://t.me/username/12345      — ссылка на сообщение (возьмётся сам чат)
#
# Если указан канал — программа вступит и в его чат комментариев.
# Строки, начинающиеся с #, — комментарии.
